# SNUDH 지식 베이스 크롤러 안내 (CRAWLER_INFO)

이 문서는 서울대학교치과병원(SNUDH) 웹사이트에서 수집한 지식 베이스 데이터와 크롤러의 작동 방식에 대해 설명합니다.

## 1. 수집 개요
- **대상 사이트**: [서울대학교치과병원 (SNUDH)](https://www.snudh.org)
- **최종 수집 일시**: 2026-02-07
- **수집 데이터 총계**: **323건**
- **저장 경로**: `data/snudh_knowledge.json`

## 2. 왜 `data` 폴더와 JSON 형식을 사용하나요?
`data` 폴더에 수집된 정보를 JSON 파일로 보관하는 데에는 핵심적인 이유가 있습니다.

- **안정적인 파이프라인 (도시락 원리)**: 크롤링은 네트워크 환경에 따라 실패할 확률이 높습니다. 먼저 '도시락(JSON 파일)'에 데이터를 안전하게 담아두면, 나중에 인공지능 엔진(Milvus DB 등)에 데이터를 넣을 때 다시 웹사이트에 접속할 필요 없이 매우 빠르고 안정적으로 작업할 수 있습니다.
- **데이터 검토 및 수정**: DB에 들어가기 전, 수집된 323건의 데이터가 정확한지 사람이 직접 눈으로 확인하고 필요 시 수정하기 가장 좋은 영구적인 저장소 역할을 합니다.
- **파이썬 최적화**: JSON 구조는 파이썬 언어에서 가장 빠르게 처리할 수 있는 형식이며, 전 세계 인공지능 프레임워크(LangChain 등)에서 표준으로 사용하는 데이터 포맷입니다.
- **서버 부하 방지**: 한 번 수집한 데이터를 파일로 보관함으로써, 병원 웹사이트에 반복적으로 접속하여 발생하는 부하와 차단 위험을 원천적으로 방지합니다.

## 3. 데이터 소스 상세
| 소스 이름 | 게시판 명칭 | 수집 건수 | 설명 |
| :--- | :--- | :---: | :--- |
| **FAQ** | 진료상담 FAQ | 145건 | 진료 절차, 예약, 치료 일반에 관한 잦은 질문 |
| **CommonSense** | 치아상식 | 142건 | 올바른 양치법, 임플란트 관리 등 일상 구강 상식 |
| **DiseaseInfo** | 질병정보 | 36건 | 구강암, 치주질환 등 전공의 수준의 질병 정보 |

## 3. 데이터 구조 (JSON)
각 데이터 항목은 아래와 같은 구조를 가집니다.
```json
{
  "title": "게시글 제목 (예: 임플란트 수술 후 주의사항)",
  "content": "상세 본문 텍스트 (줄바꿈 포함)",
  "source": "출처 분류 (FAQ / CommonSense / DiseaseInfo)",
  "url": "해당 정보의 원본 웹 주소"
}
```

## 4. 크롤러 주요 기술 사항 (`snudh_crawler.py`)
안정적인 데이터 수집을 위해 다음과 같은 기술이 적용되었습니다.

- **정밀 선택자 (Precise Selectors)**: BeautifulSoup4를 사용하여 목록 (`table tbody tr td a`) 및 본문 (`div#dbdata`) 구조를 정확히 파싱합니다.
- **자동 재시도 (Auto Retry)**: 서버 부하로 인한 503 오류 발생 시 최대 5회까지 자동 재시도합니다.
- **지수 백오프 (Exponential Backoff)**: 재시도 마다 대기 시간을 2배씩 늘려(2s -> 4s -> 8s...) 서버 차단을 방지하고 부하를 최소화합니다.
- **SSL 검증 무시**: 병원 서버의 SSL 인증서 호환성 문제를 해결하기 위해 `verify=False` 옵션을 사용합니다.

## 5. 실행 방법
프로젝트 루트 디렉토리에서 아래 명령어를 실행합니다.
```bash
python3 src/denticheck_ai/pipelines/rag/crawler/snudh_crawler.py
```

## 6. 향후 활용 계획
수집된 `snudh_knowledge.json`은 `ingest.py`를 통해 **Milvus 벡터 데이터베이스**에 적재되며, DentiCheck AI 주치의가 소견서를 작성할 때 신뢰할 수 있는 의학적 근거로 활용됩니다.
